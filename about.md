# AI Level Builder

Describe a level in plain words, and an AI builds it in the editor for you.

## How to use
1. Get a free API key from **Google AI Studio** (aistudio.google.com → Get API key).
2. Open this mod's settings in Geode and paste it into **API Key**.
3. Open any level in the editor and tap the **AI** button.
4. Type your idea, for example *"easy cube level with jump pads and a few triple spikes"*, then tap **Build**.

Tap **Undo AI** in the same popup to remove the last build.

## Providers
- **gemini** (default, free key available)
- **claude**
- **openai**
- **custom**: any OpenAI-compatible server, like Groq or OpenRouter
